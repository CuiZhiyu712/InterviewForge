# 崔智宇｜Java 后端与大模型应用面试题库

一个无需服务器、双击即可使用的单文件面试题库，面向大模型应用开发日常实习。

## 内容

- 84 道原创参考答案，覆盖 Java 后端、网络、操作系统、MySQL、Redis、LLM、RAG、Agent、MCP、SSE、框架和简历专项。
- 1,200 条公开题目/文章来源目录，可搜索并跳转原网页。
- 模块刷题、随机刷题、难度筛选、简历重点筛选、答案折叠和本地学习进度。

## 使用

直接打开 `dist/index.html`。学习状态保存在浏览器 `localStorage`，文件不会上传数据。

重新构建：

```powershell
npm run sources
npm run build
npm test
```

## 来源与边界

来源目录来自小林 Coding 与小林面试笔记在 2026-09-14 可访问的公开页面。项目仅整理公开标题与原页面链接，不复制原文答案、图片或付费内容；核心题答案为本项目重新撰写。请通过页面中的来源链接阅读原作者内容。

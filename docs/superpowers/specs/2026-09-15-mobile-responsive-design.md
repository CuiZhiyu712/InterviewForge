# InterviewForge 移动端响应式改版设计

## 目标

在不改变题库数据和学习记录格式的前提下，减少首屏占用，消除手机端吸顶筛选栏遮挡，并让 P0、模块与筛选功能适合触屏使用。

## 设计

- 将“简历 P0 作战顺序”改成默认折叠的 `details` 区域，摘要展示 P0 数量，展开后保留主题列表并提供“一键只刷 P0”。
- 将筛选控件包进筛选面板：桌面默认展开且隐藏摘要，手机默认收起并显示摘要；手机端工具栏取消 sticky。
- 手机端侧栏改成紧凑页头，模块导航横向滚动；压缩 Hero、统计卡片、题目卡片与操作区间距。
- “只刷 P0”会选中 P0 筛选、关闭随机模式、刷新列表并滚动到题目区域。
- 保留现有 localStorage 键和所有筛选、随机、收藏、错题功能。

## 验证

- 静态测试校验 P0 折叠区、筛选面板、P0 快捷入口与移动端非 sticky 规则存在。
- 浏览器脚本语法检查和全量构建测试继续通过。
- 构建后的 HTML 仍内嵌 1,200 道完整题目。
